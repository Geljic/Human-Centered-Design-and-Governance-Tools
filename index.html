About This Pilot

🎯

Purpose

These tools support HCD practitioners in moving faster from research to insight to action.

🔒

Privacy & Data

All tools run entirely in your browser. No data is sent to external servers unless you explicitly connect an AI API key. Transcripts stay on your device.

📁

Sharing & Handoff

Each tool has an Export JSON button. Share the JSON file with teammates so they can pick up where you left off.

🚀

Getting Started

Select a tool above to begin. Each tool includes built-in guidance.
